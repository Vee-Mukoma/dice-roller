# 🎲 Dice Roller

A dice roll simulator built with HTML, CSS and vanilla JavaScript.

## 🔗 Live Demo

https://vee-mukoma.github.io/dice-roller/

## 📋 Description

Dice Roller is a web app that simulates rolling dice. Users can select how many dice to roll (1-3) and choose the type of dice (D4, D6, D8, D10, D12, D20). The app instantly displays each individual roll and the total.

## ✨ Features

- Select number of dice (1-3)
- Choose dice type — D4, D6, D8, D10, D12, D20
- Displays individual roll results
- Displays total of all rolls
- Neon themed UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## 🚀 How to Run Locally

1. Clone the repository

```bash
   git clone https://github.com/vee-mukoma/dice-roller.git
```

2. Open the project folder

3. Open `index.html` in your browser
